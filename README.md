# Калькулятор рациона для доставки еды (учебный кейс)

Страница по учебному брифу: сервис доставки готовых рационов на неделю, клиенты путаются, сколько порций нужно семье. Указываешь программу, сколько взрослых и детей, на сколько дней и сколько приёмов пищи. Получаешь сумму, порции и меню на каждый день. Цены и меню условные, фото созданы нейросетью.

- 3 программы (Classic, Balance, Vegan), 3 или 5 приёмов пищи, детская порция, скидка за длительность
- Меню по дням с числом порций каждого блюда
- Ссылка сохраняет расчёт, кнопки «Поделиться» и «Скопировать»
- Окно «Не спешите уходить!» с расчётом посетителя, один раз за визит
- Расчёт вынесен в `calc.js` и работает в Node, поэтому его можно подключить к боту: `C.formatText(C.calculate({...}, D))`
- Цены, скидки и меню в одном файле `data.js`
- Проверка расчёта: `node test.js`
